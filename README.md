# Python Mini Projects

A collection of small Python projects built while learning and practicing Python.

## Projects

- **Band Name Generator** — Generates a band name based on user input.
- **Tip Calculator** — Calculates the amount each person should pay after including a tip.
- **Rock Paper Scissors** — A command-line Rock Paper Scissors game.
- **Password Generator** — Generates randomized passwords based on the requested number of letters, symbols, and numbers.
- **Hangman Game** — A command-line word guessing game.
- **Guess the Number** — A number guessing game.
- **Caesar Cipher** — Encrypts and decrypts text using the Caesar cipher.
- **Blind Auction** — Simulates a blind auction where users enter bids.
- **Blackjack Game** — A command-line implementation of the Blackjack game.

## About

These projects were created while learning and practicing Python. They cover a range of concepts including variables, user input, conditionals, loops, functions, lists, modules and libraries, randomization, and basic problem-solving.
